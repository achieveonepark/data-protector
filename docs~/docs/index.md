# Data Protector

**Unity 데이터 보안.**
한 줄의 API로 게임 데이터를 압축하고, 암호화하고, 무결성을 검증하세요.

## 특징

- 🔐 **AES-GCM 암호화** — 인증 암호화 방식으로 데이터 읽기와 조작을 동시에 방지합니다. 잘못된 키나 변조된 데이터는 복호화 즉시 예외가 발생합니다.
- 📦 **Gzip 압축** — 암호화 전에 데이터를 압축하여 저장 용량을 줄이고 대용량 데이터 처리 성능을 향상시킵니다.
- 🔍 **SHA-256 무결성 검증** — 상수 시간 비교로 데이터 해시를 계산하고 검증합니다. 타이밍 공격에 안전합니다.
