# Data Protector

**Unity Data Security.**
Compress, encrypt, and verify your game data with a simple one-line API.

## Features

- 🔐 **AES-GCM encryption** — Authenticated encryption prevents both reading and tampering. A wrong key or modified data throws immediately on decryption.
- 📦 **Gzip compression** — Compresses data before encryption to reduce storage size and improve throughput for large payloads.
- 🔍 **SHA-256 integrity check** — Computes and verifies data hashes using constant-time comparison, safe against timing attacks.
